# Redius Sales Intelligence Dashboard

Public static demonstration site, deployed using GitHub Pages.

## Publish
In **Settings → Pages**, select **GitHub Actions** as the Build and deployment source. The deployment workflow then publishes every push to main.

Expected address after a successful deployment: https://omniblessing.github.io/redius-sales-dashboard/

## Privacy
Never commit customer email lists, confidential brochures, or credentials to this public repository. All displayed company examples are fictional. The website cannot scan live company websites without a separate backend. Gmail sending is disabled.
